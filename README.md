# 🐿️ 다람쥐 뽀모도로 (Daramzi Pomodoro)

집중 타이머에 다람쥐 캐릭터 육성·수집을 결합한 **앱인토스(Apps in Toss) 미니앱** 프로토타입입니다.
집중하는 동안 다람쥐가 도토리를 모으고, 집중에 성공하면 도토리를 재화로 받아 다람쥐를 꾸미거나 친구를 도감에 모읍니다.

> 📄 상세 기획은 [`docs/다람쥐_뽀모도로_요구사항명세서.md`](docs/다람쥐_뽀모도로_요구사항명세서.md) 참고

## 핵심 규칙

| 규칙 | 값 |
| --- | --- |
| 집중 시간 | 5~60분 (기본 25분, 5분 단위) |
| 도토리 적립 | **5분당 1개** (집중 시간 비례) |
| 집중 성공 | 적립분 **100%** 지급 |
| 중도 포기 / 화면 이탈 | 적립분 **50%** 지급 |
| 다람쥐 친구 | 도감 수집 전용 (능력치 효과 없음) |
| 결제 | 없음 (도토리는 집중으로만 획득) |

## 기능

- ⏱️ **집중 타이머** — 시간 설정, 카운트다운, 도토리 모으기 애니메이션
- 🚪 **이탈 감지** — 집중 중 다른 화면/앱으로 전환하면 자동 '포기'(50%) 처리
- 🛍️ **꾸미기 상점** — 모자 3 · 목도리 2 · 반지 2 · 하늘 배경 2 · 바닥 배경 2
- 📖 **친구 도감** — 다람쥐 친구 4종(기본 1 + 수집 3)
- 💾 **저장** — 도토리·아이템·친구·꾸미기 상태를 `localStorage`에 저장

## 실행 방법

별도 빌드 없이 정적 파일로 동작합니다.

```bash
# 저장소 루트에서 간단한 정적 서버 실행
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

또는 `index.html`을 브라우저로 바로 열어도 됩니다.

## 파일 구조

```
index.html   # 화면 마크업
styles.css   # 토스 톤의 스타일
app.js       # 게임 로직(타이머·도토리·상점·도감·저장)
docs/        # 요구사항 명세서
```

## 앱인토스 연동 메모

- 이 프로토타입은 **WebView 방식** 미니앱으로 바로 감쌀 수 있는 순수 웹(HTML/CSS/JS) 구현입니다.
- 추후 RN(Granite) 방식으로 이식하거나, 앱인토스 콘솔에서 WebView 미니앱으로 등록 → 샌드박스 테스트 → 검수 → 출시 단계로 진행할 수 있습니다.
- 토스 UI 가이드(색상·라운드·하단 탭)를 참고해 스타일을 맞췄습니다.
