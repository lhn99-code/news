# 🐿️ 다람쥐 뽀모도로 — 요구사항 명세서

> 앱인토스(Apps in Toss) 미니앱 / 작성일: 2026-06-20

---

## 1. 개요

**다람쥐 뽀모도로**는 집중 타이머(뽀모도로)에 다람쥐 캐릭터 육성·수집 재미를 결합한 미니앱입니다.
사용자가 집중하는 동안 다람쥐가 나무에 도토리를 모으고, 집중에 성공하면 도토리를 재화로 획득합니다.
모은 도토리로 다람쥐를 꾸미거나 새로운 다람쥐 친구를 데려올 수 있어, **집중할수록 보상이 쌓이는** 선순환을 제공합니다.

| 항목 | 내용 |
| --- | --- |
| 제품명 | 다람쥐 뽀모도로 |
| 플랫폼 | 앱인토스 미니앱 (토스 앱인앱) |
| 한 줄 소개 | 집중하면 도토리가 쌓이고, 다람쥐를 꾸미는 귀여운 뽀모도로 타이머 |
| 핵심 가치 | 집중(생산성) + 수집·꾸미기(보상) |

---

## 2. 목표

- **주 목표:** 사용자가 꾸준히 집중 세션을 완료하도록 동기를 부여한다.
- **부 목표:** 도토리 재화를 통한 꾸미기·수집으로 재방문(리텐션)을 높인다.
- **비목표(이번 범위 아님):** 일정 관리, 할 일(To-do) 목록, 친구 간 소셜 랭킹 — *향후 확장 후보로만 둠.*

---

## 3. 핵심 컨셉 루프

```
집중 시작(타이머)  →  다람쥐가 나무에 도토리 모으는 애니메이션
        →  집중 시간에 비례해 도토리 적립
        →  집중 성공 시 도토리 획득(중도 포기 시 절반)
        →  도토리로 다람쥐 꾸미기 / 친구 영입
        →  친구가 많을수록 도토리 적립 속도 ↑  →  다시 집중
```

## 4. 기능 요구사항 (Functional Requirements)

### 4.1 집중 타이머 (뽀모도로)

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-T1 | 기본 집중 시간 25분 | 앱 진입 시 기본값 25분으로 설정 |
| FR-T2 | 집중 시간 사용자 설정 | 사용자가 원하는 시간으로 변경 가능 (예: 5~60분, *세부 범위 협의 필요*) |
| FR-T3 | 타이머 시작/일시정지/종료 | 시작 후 진행, 중도 종료(포기) 가능 |
| FR-T4 | 진행 중 도토리 모으기 애니메이션 | 집중 중 다람쥐가 나무에 도토리를 나르는 애니메이션 표시 |
| FR-T5 | 집중 완료 처리 | 설정 시간을 모두 채우면 "집중 성공" 처리 및 도토리 전량 지급 |
| FR-T6 | 중도 포기 처리 | 타이머 종료/이탈 시 **그때까지 적립분의 50%만** 지급 |

### 4.2 도토리(재화) 시스템

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-A1 | 시간 비례 적립 | 도토리는 집중 시간에 비례해 적립 (예: 1분당 N개 — *적립 단가 협의 필요*) |
| FR-A2 | 성공 보상 | 집중 성공 시 적립분 100% 지급 |
| FR-A3 | 포기 보상 | 중도 포기 시 적립분 50% 지급 |
| FR-A4 | 보유 도토리 표시 | 현재 보유 도토리 수량을 항상 확인 가능 |
| FR-A5 | 도토리 소비 | 꾸미기 아이템 구매 / 다람쥐 친구 영입에 사용 |

### 4.3 다람쥐 꾸미기

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-D1 | 착용 아이템 | 모자, 목도리, 반지 등 다람쥐에게 착용 가능한 아이템 |
| FR-D2 | 배경 아이템 | 하늘 배경, 바닥 배경 등 환경 꾸미기 아이템 |
| FR-D3 | 아이템 구매 | 도토리로 아이템 구매 (상점) |
| FR-D4 | 아이템 장착/해제 | 보유 아이템을 다람쥐/배경에 장착·해제 |
| FR-D5 | 꾸민 상태 저장 | 사용자의 꾸미기 상태를 저장·복원 |

### 4.4 다람쥐 친구 (수집 + 효과)

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-F1 | 친구 영입 | 도토리를 일정량 모으면 새로운 다람쥐 친구 획득 가능 |
| FR-F2 | 적립 속도 증가 효과 | 친구가 많을수록 도토리 **적립 속도가 빨라짐** |
| FR-F3 | 친구 도감/목록 | 보유한 다람쥐 친구를 모아 보는 화면 |
| FR-F4 | 효과 누적 규칙 | 친구별 적립 보너스가 어떻게 합산되는지 규칙 정의 (*협의 필요*) |

## 5. 화면 구성 (초안)

1. **메인(타이머) 화면**
   - 중앙: 다람쥐 + 나무 + 도토리 애니메이션
   - 상단: 보유 도토리 수량
   - 하단: 집중 시간 설정 / 시작 버튼
2. **집중 진행 화면**
   - 남은 시간 표시, 다람쥐가 도토리 모으는 연출, 포기 버튼
3. **상점 / 꾸미기 화면**
   - 착용 아이템(모자·목도리·반지), 배경 아이템(하늘·바닥) 탭
   - 구매 / 장착·해제
4. **다람쥐 친구 도감 화면**
   - 보유 친구 목록, 영입 가능한 친구, 적립 보너스 표시

## 6. 데이터 모델 (개념 수준)

```
User
 ├─ acorns: int                 # 보유 도토리
 ├─ timerDefaultMinutes: int    # 기본 25
 ├─ ownedItems: [ItemId]        # 보유 꾸미기 아이템
 ├─ equippedItems: {slot: ItemId}  # 장착 상태 (hat, scarf, ring, skyBg, floorBg)
 └─ ownedSquirrels: [SquirrelId]   # 보유 다람쥐 친구

FocusSession
 ├─ targetMinutes: int
 ├─ elapsedMinutes: int
 ├─ status: completed | abandoned
 └─ acornsEarned: int           # status에 따라 100% / 50%

Item
 ├─ id, type(hat|scarf|ring|skyBg|floorBg)
 └─ price: int

Squirrel
 ├─ id, name
 └─ acornRateBonus: float       # 적립 속도 보너스
```

## 7. 비기능 요구사항 (Non-Functional)

- **플랫폼:** 앱인토스 미니앱 가이드 및 토스 UI 가이드 준수 (검수 통과 목표)
- **저장:** 도토리·아이템·친구·꾸미기 상태는 영구 저장(로컬 또는 서버)되어 재진입 시 복원
- **백그라운드 타이머:** 앱을 잠시 벗어나도 타이머 진행 상태가 정확히 반영되어야 함 (*정책 협의 필요*)
- **성능:** 애니메이션이 부드럽고 배터리 부담이 적어야 함
- **접근성/감성:** 귀엽고 직관적인 UI, 집중을 방해하지 않는 차분한 톤

## 8. 협의가 필요한 미정 항목 (Open Questions)

1. **집중 시간 설정 범위** — 최소/최대 몇 분까지 허용할지 (예: 5~60분?)
2. **도토리 적립 단가** — 1분당 몇 개? 집중 시간이 길수록 보너스 가중치를 줄지?
3. **친구 적립 보너스 합산 방식** — 합연산(+10%, +10%) vs 곱연산, 상한 여부
4. **백그라운드/이탈 판정** — '포기'로 간주하는 기준(앱 종료, 타 화면 전환 등)
5. **아이템·친구 종류 수와 가격표** — 초기 출시(MVP)에 몇 종을 넣을지
6. **결제 요소 유무** — 도토리를 현금으로 구매하는 인앱결제 도입 여부 (이번 범위 제외 가정)

## 9. MVP 범위 제안

> 첫 출시(검수 통과)를 빠르게 하기 위한 최소 기능 묶음

- ✅ 25분 기본 + 시간 설정 타이머
- ✅ 집중 중 도토리 모으기 애니메이션 (다람쥐 1종)
- ✅ 시간 비례 적립 + 성공 100% / 포기 50%
- ✅ 꾸미기 아이템 각 슬롯 1~2종(모자·목도리·배경) + 상점
- ✅ 다람쥐 친구 2~3종 + 적립 속도 보너스
- 🔜 (이후) 도감 확장, 시즌 아이템, 통계, 소셜 등
