## 1. 개요

**다람쥐 뽀모도로**는 집중 타이머(뽀모도로)에 다람쥐 캐릭터 육성·수집 재미를 결합한 미니앱입니다.
사용자가 집중하는 동안 다람쥐가 도토리를 모으고, 집중에 성공하면 도토리를 재화로 획득합니다.
모은 도토리로 다람쥐를 꾸미거나(상점) 새로운 다람쥐를 도감에 수집하며, **집중할수록 보상이 쌓이는** 선순환으로 꾸준한 집중 습관을 만드는 것이 목표입니다.

| 항목 | 내용 |
| --- | --- |
| 제품명 | 다람쥐 뽀모도로 |
| 플랫폼 | 앱인토스 미니앱 (토스 앱인앱) |
| 한 줄 소개 | 집중하면 도토리가 쌓이고, 다람쥐를 키우는 귀엽고 포근한 뽀모도로 타이머 |
| 핵심 가치 | **집중력 향상(생산성)** + **게이미피케이션을 통한 습관 형성** |
| 주 타겟 | 자기계발·습관 형성을 원하는 사용자 (독서·운동·사이드프로젝트 등 꾸준한 루틴을 들이고 싶은 사람) |
| 북스타 메트릭 | **재방문·리텐션** (매일 돌아와 꾸준히 쓰는가 — DAU·재방문율·평균 streak) |

---

## 2. 목표

- **주 목표:** 사용자가 매일 돌아와 집중 세션을 완료하도록 동기를 부여하고 **습관화**한다. (리텐션 중심)
- **부 목표:** 도토리 재화·꾸미기·도감 수집과 연속(streak) 보상으로 재방문 유인을 강화한다.
- **확산 목표:** 친구 공유·초대와 랭킹으로 자연스러운 바이럴을 만든다. (Phase 2)
- **비목표(이번 범위 아님):** **할 일(Task) 관리 / To-do 목록** — 향후 확장 후보로만 둠.

---

## 3. 핵심 컨셉 루프

```
집중 시작(타이머)  →  다람쥐가 도토리 모으는 레트로 도트 애니메이션
        →  집중 시간에 비례해 도토리 적립
        →  세션 완료 시 도토리 지급 (+ 연속 성공/일일 streak 보너스)
        →  (선택) 리워드 광고 시청 시 도토리 추가 획득
        →  도토리로 다람쥐 꾸미기(상점) / 새 다람쥐 도감 수집
        →  꾸민 다람쥐·성과를 친구에게 공유 / 랭킹 경쟁  →  다시 집중
```

## 4. 기능 요구사항 (Functional Requirements)

### 4.1 집중 타이머 (뽀모도로) — `MVP`

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-T1 | 기본 집중 시간 25분 | 앱 진입 시 기본값 25분 |
| FR-T2 | 집중 시간 사용자 설정 | 원하는 시간으로 변경 가능 (범위: **5~60분**) |
| FR-T3 | 타이머 시작/일시정지/종료 | 시작 후 진행, 중도 종료(포기) 가능 |
| FR-T4 | 진행 중 도토리 모으기 애니메이션 | 집중 중 다람쥐가 도토리를 모으는 도트 애니메이션 표시 |
| FR-T5 | 집중 완료 처리 | 설정 시간을 모두 채우면 "집중 성공" 처리 및 도토리 지급 |
| FR-T6 | 중도 포기 처리 | 타이머 종료/이탈 시 그때까지 적립분의 **50%만** 지급 |
| FR-T7 | 이탈 = 포기 | 집중 중 앱 종료뿐 아니라 **다른 화면 전환/백그라운드 전환도 '포기'로 간주** |

### 4.2 도토리(재화) 시스템 — `MVP`

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-A1 | 시간 비례 적립 | 도토리는 집중 시간에 비례해 적립 — **5분당 1개** |
| FR-A2 | 세션 완료 보상 | 집중 성공(세션 완료) 시 적립분 100% 지급 |
| FR-A3 | 연속(streak) 보너스 | 연속 성공/일일 연속 출석에 따라 **보너스 도토리** 추가 지급 (아래 4.3) |
| FR-A4 | 포기 보상 | 중도 포기 시 적립분 50% 지급 |
| FR-A5 | 리워드 광고 보상 | (선택 행동) 광고 시청 시 도토리 추가 획득 — 수익화 겸 보상 (아래 4.6) |
| FR-A6 | 보유 도토리 표시 | 현재 보유 도토리 수량을 항상 확인 가능 |
| FR-A7 | 도토리 소비 | 꾸미기 아이템 구매 / 다람쥐 도감 영입에 사용 |

### 4.3 연속(Streak) 보상 — `MVP`

> 리텐션이 북스타 메트릭이므로, "매일 돌아오게 만드는" 연속 보상을 1차 기능으로 포함합니다.

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-S1 | 일일 streak 카운트 | 하루 1세션 이상 완료 시 연속 일수 +1, 거른 날엔 초기화(또는 1회 보호) |
| FR-S2 | streak 보너스 도토리 | 연속 일수가 늘수록 세션 완료 보너스 도토리 증가 (예: 3일·7일·14일 마일스톤) |
| FR-S3 | streak 시각화 | 현재 연속 일수와 다음 보너스까지 남은 진행도를 표시 |

### 4.4 다람쥐 꾸미기 (상점) — `MVP`

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-D1 | 착용 아이템 | 모자, 목도리, 반지 등 다람쥐 착용 아이템 |
| FR-D2 | 배경 아이템 | 하늘 배경, 바닥 배경 등 환경 꾸미기 |
| FR-D3 | 아이템 구매(상점) | 도토리로 아이템 구매 |
| FR-D4 | 아이템 장착/해제 | 보유 아이템을 다람쥐/배경에 장착·해제 |
| FR-D5 | 꾸민 상태 저장 | 꾸미기 상태를 저장·복원 (로컬+서버 동기화) |

### 4.5 다람쥐 도감 (수집·컬렉션) — `MVP`

> 도감은 **수집 전용** 콘텐츠입니다. 도토리 적립 속도 등 게임 능력치 효과는 **없습니다.**

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-C1 | 다람쥐 영입 | 도토리를 일정량 모으면 새로운 다람쥐 획득 |
| FR-C2 | 도감 화면 | 보유 다람쥐를 모아 보는 컬렉션 화면 |
| FR-C3 | 미보유 표시 | 아직 얻지 못한 다람쥐는 실루엣/잠금으로 노출해 수집 욕구 자극 |

### 4.6 수익화 — 리워드 광고형 — `MVP(경량)`

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-M1 | 리워드 광고 | 사용자가 원할 때 광고를 보면 도토리를 추가로 받음 (강제 노출 아님) |
| FR-M2 | 광고 빈도 제한 | 일일 시청 횟수 상한 등으로 과도한 노출 방지, 집중 경험 보호 |
| FR-M3 | 정책 준수 | 앱인토스/토스 광고·심사 정책 및 광고 SDK 연동 가능 여부 확인 필요 (*협의 항목*) |

> 참고: **현금 인앱결제(IAP)는 사용하지 않습니다.** 도토리는 ①집중 ②연속 보너스 ③리워드 광고로만 획득합니다.

### 4.7 소셜 — 친구·공유·랭킹 — `Phase 2`

> 사용자 식별이 필요하므로 **토스 로그인 연동이 사실상 전제**입니다(아래 6장 참조). MVP 이후 단계로 둡니다.

| ID | 요구사항 | 상세 |
| --- | --- | --- |
| FR-R1 | 공유 | 꾸민 다람쥐/성과(집중 시간·streak)를 친구에게 공유·초대 |
| FR-R2 | 친구 목록 | 친구를 추가/연결 (토스 친구 연동 활용 검토) |
| FR-R3 | 랭킹·리더보드 | 집중 시간 또는 도토리 기준 친구/전체 순위 경쟁 |

## 5. 화면 구성 (초안)

1. **메인(타이머) 화면** — 중앙: 다람쥐+도토리 도트 애니메이션 / 상단: 보유 도토리·현재 streak / 하단: 시간 설정·시작
2. **집중 진행 화면** — 남은 시간, 도토리 모으는 연출, 포기 버튼
3. **상점/꾸미기 화면** — 착용 아이템(모자·목도리·반지), 배경 아이템(하늘·바닥) 탭 / 구매·장착·해제
4. **다람쥐 도감 화면** — 보유 다람쥐, 영입 가능, 미보유(실루엣)
5. **(Phase 2) 랭킹/친구 화면** — 리더보드, 친구 목록, 공유·초대

## 6. 데이터 모델 (개념 수준)

```
User
 ├─ userId: string              # 토스 로그인 식별자 (소셜/동기화 시 필요)
 ├─ acorns: int                 # 보유 도토리
 ├─ timerDefaultMinutes: int    # 기본 25
 ├─ streakDays: int             # 현재 연속 일수
 ├─ lastSessionDate: date       # streak 판정용
 ├─ ownedItems: [ItemId]
 ├─ equippedItems: {slot: ItemId}   # hat, scarf, ring, skyBg, floorBg
 └─ ownedSquirrels: [SquirrelId]

FocusSession
 ├─ targetMinutes / elapsedMinutes: int
 ├─ status: completed | abandoned
 ├─ acornsEarned: int           # 100% / 50%
 └─ bonusAcorns: int            # streak 보너스

Item     { id, type(hat|scarf|ring|skyBg|floorBg), price }
Squirrel { id, name, unlockCost }   # 도감 수집용, 능력치 효과 없음
```

**저장 정책:** **로컬 + 서버 동기화(절충형)**. 평소엔 기기 로컬에 저장해 오프라인에서도 동작하고, 토스 로그인 시 서버와 동기화해 기기 변경·랭킹·친구 기능을 지원합니다.

## 8. 비기능 요구사항 (Non-Functional)

- **플랫폼:** 앱인토스 미니앱 가이드 및 토스 UI/심사 정책 준수 (검수 통과 목표)
- **저장/동기화:** 도토리·아이템·도감·꾸미기·streak 상태는 영구 저장되어 재진입 시 복원, 로그인 시 서버 동기화
- **백그라운드 타이머:** 앱을 잠시 벗어나도 타이머 상태가 정확히 반영 (FR-T7 정책과 연계, *협의 필요*)
- **성능:** 도트 애니메이션이 부드럽고 배터리 부담이 적어야 함
- **감성/접근성:** 집중을 방해하지 않는 차분하고 직관적인 UI
- **아트 스타일:** **포근하고 귀여운 토스풍 디자인** — 둥근 모서리·넉넉한 여백·부드러운 그림자·토스 블루를 활용한 깔끔하고 친근한 톤. 다람쥐·도토리·아이템은 둥글둥글하고 따뜻한 일러스트로 제작 (이모지는 개발용 임시 표현)

## 9. 확정된 항목 (Decisions)

- **핵심 가치:** 집중력 향상 + 게이미피케이션 습관 형성 (둘의 결합)
- **타겟:** 자기계발·습관 형성 사용자
- **북스타 메트릭:** 재방문·리텐션
- **집중 시간:** 5~60분 (기본 25분)
- **도토리 적립:** 5분당 1개 (시간 비례)
- **보상 규칙:** 세션 완료 시 100% 지급 + **연속(streak) 보너스**, 중도 포기 시 50%
- **이탈 판정:** 다른 화면 전환/백그라운드 전환도 '포기'로 간주
- **도토리 사용처:** **꾸미기 상점 + 도감·컬렉션**
- **수익화:** **리워드 광고형** (현금 IAP 없음)
- **소셜:** 친구·공유 + 랭킹·리더보드 (Phase 2, 토스 로그인 전제)
- **데이터 저장:** 로컬 + 서버 동기화
- **아트:** 포근·귀여운 토스풍 디자인 (둥글고 깔끔한 톤) — *v2 초안의 레트로·도트에서 변경*
- **제외(out of scope):** 할 일(Task) 관리

### 9.1 MVP 콘텐츠 구성 (가격표 예시)

| 분류 | 종류 | 슬롯/수량 | 가격(도토리) 예시 |
| --- | --- | --- | --- |
| 모자 | 3종 | hat | 10 / 15 / 20 |
| 목도리 | 2종 | scarf | 12 / 18 |
| 반지 | 2종 | ring | 15 / 25 |
| 하늘 배경 | 2종 | skyBg | 25 / 35 |
| 바닥 배경 | 2종 | floorBg | 25 / 35 |
| 다람쥐(도감) | 4종 (기본 1 + 수집 3) | 도감 | 0 / 50 / 100 / 200 |

> 25분 집중 = 도토리 5개. 첫 모자(10개) ≈ 2세션, 첫 다람쥐(50개) ≈ 10세션.

## 10. 출시 단계(Phase) 제안

### Phase 0 — MVP (검수 통과 & 첫 출시)
- ✅ 25분 기본 + 시간 설정 타이머 (5~60분)
- ✅ 집중 중 도토리 모으기 도트 애니메이션 (다람쥐 1종)
- ✅ 시간 비례 적립 + 세션 완료 100% / 포기 50% + **streak 보너스**
- ✅ 꾸미기 상점(슬롯별 1~2종) + 다람쥐 도감 2~3종 수집
- ✅ 로컬 저장 (서버 동기화는 로그인 도입과 함께)
- ✅ 리워드 광고(경량) — 정책·SDK 확인 후
